# Privacy Policy / 隐私政策

Last updated: 2026-11-01

## English

Blue V follow-back check is a local Microsoft Edge / Chrome extension.

It does **not** collect, sell, or send your X password, cookies, or personal profile to any server we operate. There is no analytics account and no remote database.

What stays on your computer:

- The language you chose
- The day range you chose
- Handles first seen during a scan you started, so later scans can estimate how long you have been following them

The extension only reads the Following list after **you** click Start, and only in the X tab you already opened. You can remove all local data by deleting the extension.

Contact: open an issue at https://github.com/JiahaoJahao/x-blue-back

## 中文

「蓝V回关检查」是一个本地 Edge / Chrome 扩展。

它**不会**收集、出售或把你的 X 密码、Cookie、个人资料发到我们运营的任何服务器。没有统计账号，也没有远程数据库。

只保存在你这台电脑上的内容：

- 你选的语言
- 你选的天数范围
- 你主动开始检查时第一次看到的账号，方便下次估算关注天数

只有在你点「开始检查」之后，它才会读取你已经打开的关注列表。删除扩展即可清掉这些本地数据。

联系：https://github.com/JiahaoJahao/x-blue-back
